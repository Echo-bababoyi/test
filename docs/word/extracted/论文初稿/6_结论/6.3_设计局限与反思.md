# 6.3 设计局限与反思

本研究存在以下局限：

第一，可用性测试尚不完善。 测试样本仅 4 人，数量较少，难以代表更广泛的老年用户群体。虽然采集了 SUS 和补充问卷，但样本量小，结论的统计效度有限；同时未系统采集任务完成时间等量化指标，对用户体验的客观刻画不够充分。此外，测试环境与真实场景存在差异，用户可能在被观察的状态下表现出与日常使用不同的行为。

第二，场景覆盖有限。 本研究聚焦 4 个政务场景，能够系统演示受控响应型代理的能力矩阵和三原则边界，但未覆盖浙里办全部服务场景。未覆盖场景的代理能力需要逐场景扩展 prompt 和工具集，且新场景可能引入新的敏感操作类型，如社保卡挂失涉及证件冻结、异地就医备案需要跨部门信息核验等，现有分级机制是否需要调整尚未验证。

第三，技术实现尚不完备。原型以 Web 形式运行，并非完整原生应用，在用户体验上与真实产品存在一定差异。同时，相关数据和信息均为模拟数据，未对接真实接口。部分流程因技术难度较大采用了替代方案，例如短信验证码的读取使用浏览器弹窗模拟，而非调用系统短信权限。

第四，未评估长期使用中的信任演化。 本研究为一次性接触测试，无法观察老年用户在多次使用后对代理信任度的变化。信任建立往往需要反复的正向体验积累，而一次失败就可能造成长期抵触。目前缺乏对信任动态变化规律的探讨。

第五，代理的主动引导能力仍有不足。 在测试中，当用户遇到人脸识别困难时，代理仅能重复“请缓慢摇头”等固定提示，无法根据用户具体失败原因，如动作幅度太小、光线不足给出针对性建议。这表明当前设计中代理的感知能力和自适应能力仍较初级。

第六，多模态交互的协同深度有限。 虽然实现了“语音+视觉”双通道冗余，但触控与语音之间的切换仍显生硬（例如用户语音输入中途想改用点按，需要手动关闭麦克风）。更自然的多模态融合尚未探索。
