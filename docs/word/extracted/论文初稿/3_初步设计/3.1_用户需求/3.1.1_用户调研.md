# 3.1.1 用户调研

本研究采用结合参与式观察与半结构式访谈的质性研究方法。

调研场域：杭州市西湖区港湾家园、三坝雅苑、古荡新村三个典型老年社区，以及古荡菜市场（高频数字支付场景）与西湖区政务大厅（政务服务高频场景）。三个社区分别代表不同的老年居住类型：港湾家园为紧邻高校的居住型社区，三坝雅苑为回迁安置小区，古荡新村为建设于 20 世纪 80 年代的老牌居民区，居住着大量本地老年居民。政务大厅作为老年用户办理社保查询、医保报销、养老资格认证等服务的核心场所，每日聚集大量老年群体，能够在真实的政务服务语境下观察老年人的操作行为与情绪反应。

调研样本：7 位 60 岁及以上老年用户，通过社区渠道目的性抽样招募，覆盖不同年龄段（60—75 岁）、文化程度（初中至大专）、智能手机使用年限（2—8 年）与居住状况（独居/与子女同住）。作为质性研究的初步探索，该样本量符合信息饱和原则。

访谈设计：访谈在受访者熟悉的居住社区进行，单次时长约 30 分钟，全部录音并整理转写为文本。访谈围绕三条主线展开：日常数字生活习惯；对信息服务 APP 的认知与使用体验；操作过程中的主要障碍与需求。访谈同时设置任务测试环节，要求受访者在无辅助状态下完成查找养老金发放记录、查询医保缴费记录两个典型任务，研究者记录操作过程与情绪反应。
