# 3.1.2 核心痛点

基于上述调研，本研究梳理出以下三个层面的核心痛点。

第一，导航入口迷失，高频功能入口隐蔽，搜索体验欠佳。老年用户在查找养老金认证等功能时，因首页入口不明显，被迫依赖搜索栏，但手写输入识别率低，语音搜索对方言支持不足，搜索功能亦未将高频事项显性前置。7位受访者中，有6位在任务测试环节中途迷失，平均探索时间超过3分钟。

第二，认知障碍。具体表现为四类问题：一是返回逻辑混乱，多位受访者对页面连续返回逻辑不适应，习惯性点击一次返回即认为已退出流程，但部分服务需多次返回，导致误判操作失败；二是验证码输入流程中断率高，7位受访者全部在短信验证码环节遇到困难，需切换APP查看短信再返回填写，过程中页面可能刷新失效；三是人脸识别容错性差，部分功能要求完成眨眼或摇头动作，老年人动作幅度小、速度慢，常被识别为失败；四是弹窗打断流程，系统升级提示或跳转应用商店导致流程中断、信息丢失。

第三，情绪冲突。主要表现为两方面：一是缺乏操作安全网，误触返回键即导致表单数据全部丢失，系统无容错机制，用户因害怕出错而产生焦虑；二是系统未提供有效的引导机制如视频客服、屏幕共享、语音协助等，导致用户在遇到困难时只能放弃操作或转向线下求助。上述痛点共同指向一个核心问题：老年用户并非缺乏操作能力，而是系统未能提供使其安心完成操作的信任保障，这为后续受控响应型智能代理的设计提供了明确的问题导向。
