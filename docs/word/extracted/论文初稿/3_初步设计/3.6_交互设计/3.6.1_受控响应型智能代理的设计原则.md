# 3.6.1 受控响应型智能代理的设计原则

受控响应型智能代理的设计原则贯穿本研究中智能代理的所有设计决策，优先级最高，不因具体场景而妥协。具体内容如下：

代理原则上不主动。 代理在用户主动唤醒之前完全静默，不弹窗、不推送、不预判，将发起对话的权利始终留给用户。

确定性操作代理止步。 凡按下即产生不可撤销后果的操作，如登录、提交、支付等，代理只负责引导和告知，不代为执行，保障用户对最后一步的绝对掌控。

权限一事一授。 代理不持有持久化全局授权，每个涉及用户隐私或账户的敏感操作，均在当次任务中单独向用户请求授权，任务结束即失效。

这三条原则的关键在于，它们不是对话层面的约定，而是在架构层面被固化。代理不会主动发起对话或提出建议，避免打断用户的操作流程；确定性操作按钮在设计上即被排除在代理的可执行范围之外；敏感操作的授权随任务结束而自动失效。这使得代理无法越权成为一种可验证的技术保障，而非运行时的口头承诺，从而消解了老年用户对智能代理失控的深层焦虑。
