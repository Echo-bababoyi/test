# 3.6.2 受控响应型智能代理的权限等级

受控响应型智能代理的权限等级按照场景需要和用户需求分为三个等级，权限等级决定代理可以触碰什么边界。

引导级：支持语音对话、复述确认、页面跳转、语音引导和屏幕高亮，但不支持代读外部内容、代填任何字段、按确定性按钮。

半委托级：在引导级基础上增加，代读外部内容，如短信验证码，和代填非敏感字段，如手机号、缴费年度，但仍不支持代填敏感字段和按确定性按钮。

全委托级：在半委托级的基础上，进一步增加代填身份证号等认证型敏感字段。但密码、银行卡号及任何支付相关字段永远不在代理能力范围内，确定性按钮依然不代按。

能力分级的设计逻辑是用户授出多少信任，代理就获得多少权限，而不是默认最高授权。敏感字段的判断不依赖 AI 的运行时判断，而是由硬编码白名单定义，其中身份证号作为可代填敏感字段的上限，密码类信息根本不出现在白名单中。确定性操作是一条绝对红线，不存在任何等级可以越界的空间。
