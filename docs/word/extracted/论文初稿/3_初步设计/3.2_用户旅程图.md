# 3.2 用户旅程图

以“医保缴费”为代表性场景，梳理老年用户在当前旅程中的痛点与机会发现，具体如下。

图3.1 用户旅程图

登录阶段：用户不清楚授权弹窗的具体内容，因不放心而犹豫；点击授权后可能触发应用跳转，导致用户迷失操作路径；人脸识别中的眨眼、摇头等动作验证难以顺利完成。机会发现：智能代理可通过语音讲解向用户清晰说明每项授权的用途，消除不信任感，并在用户同意后代为完成跳转和验证引导。

寻找功能入口阶段：APP入口层级过深，搜索功能返回的结果复杂且分类混乱，用户难以从众多选项中快速定位“医保缴费”功能。机会发现：用户仅需通过语音告知代理“我要缴医保”，代理即可理解意图并直接完成页面跳转，绕过复杂的导航结构。

填写相关信息阶段：表单填写项多且易出错，用户对身份证号、银行卡等敏感信息存在隐私泄露担忧；此外，操作超时导致流程刷新中断，进一步加剧挫败感。机会发现：代理可帮助填写非敏感信息（如姓名、缴费年度），对敏感信息仅引导用户自行输入；草稿箱机制可自动保存已填内容，避免超时后重复劳动；同时通过一事一授权的信任机制，让用户保持对关键操作的控制感。
