# 3.7.4 代理面板视觉设计

代理面板高度占屏幕的45%，从底部滑出。上方业务页面覆盖40%透明度的黑色蒙层，但页面内容始终可见；当代理高亮某个界面元素时，该元素区域的蒙层被移除（即镂空），使目标元素透出并可点击。面板顶部设有灰色拖拽条（高4dp），标题栏高48dp，左侧显示小浙图标和“小浙”文字，右侧为关闭按钮（×）。中间为可滚动的对话气泡区，代理气泡（浅橙色）与用户气泡（浅灰色）交替排列。下方为状态行，显示当前状态（如“正在听您说话…”）。底部为麦克风大按钮（视觉直径72dp，触控区88dp），用户可按住说话。面板的整体设计保留了上方页面的可见性，让老年用户始终知道自己在哪个页面操作，避免空间定向迷失。
