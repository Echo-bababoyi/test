# 3.3 设计方案（引言）

为回应老年用户对智能代理的信任缺失与控制权的双重顾虑，本研究将智能代理定位为“受控响应型智能代理”：代理仅在获得用户明确授权后协助操作，而非主动替用户决策和执行。这一设计定位包含三层含义：一是响应性，代理根据用户指令启动，不主动打扰；二是受控性，代理的所有操作需经用户授权并保持透明，用户可随时中止；三是可委托性，用户可根据信任程度选择不同级别的权限。

受控响应型智能代理的整体设计围绕三条核心设计原则、三级权限划分以及透明化操作机制展开。三条原则从行为边界、操作授权和交互主动性三个维度定义了代理的受本质；三级权限则根据用户授出的信任程度动态调整代理的能力范围；透明化操作机制通过操作前预告、操作中反馈、操作后日志，确保代理行为可观察、可理解、可干预。
