# 3.3.2 受控响应型智能代理的权限等级

基于上述设计原则，本研究中智能代理的权限等级按场景需要分为不同的能力等级，等级决定了代理可以触碰的操作边界。这一分级思路参考了Parasuraman等提出的自动化等级模型：人与自动化的交互可在信息获取、信息分析、决策选择、行动实施四个维度上分别选择不同的自动化程度，自动化并非“全有或全无” [12]。Simmler和Frischknecht进一步指出，自动化和技术自主性本质上都是渐进的、连续谱的[15]，这一思想为本研究将代理能力划分为由低到高的三个层级提供了理论依据。

受控响应型智能代理的具体权限等级划分如下：

引导级：代理仅提供步骤提示与语音引导，不实际操作。

半委托级：代理代为填写表单中的普通字段，但不提交，最终确认由用户完成；对于敏感字段，如身份证号、短信验证码等，需单独逐次授权。

全委托级：代理完成完整流程，可以填写部分敏感字段，但不可逆操作（登录、提交、支付）和密码类凭证字段（如登录密码、支付密码）的填写仍须用户亲手完成——这是本设计的硬性底线，不因委托级别而改变。

上述分级严格遵循确定性操作代理止步的原则——凡不可逆操作，代理始终保留最后一步由用户亲自完成。
