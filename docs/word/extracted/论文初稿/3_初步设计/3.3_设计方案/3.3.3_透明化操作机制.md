# 3.3.3 透明化操作机制

为实现上述受控性与可委托性，本研究配套设计了透明化操作机制.

操作前：代理在执行关键操作前，通过语音与视觉两种方式同步预告，说明即将执行的操作内容

操作中：实时反馈操作进展，让用户随时了解代理的执行状态。

操作后：提供可追溯的操作日志，用户可随时查看代理的行为记录。

这一设计参考了现有关于 AI 系统透明化与可审计性的研究。LaRubbio 等指出，AI 助手在老年人日常生活中的应用需确保透明度，并维护用户自主权[13]。Mathur 等对 23 位老年人的实验研究表明，老年人需要 AI 系统实时解释其行为，以便理解系统状态并判断下一步行动[16]。本研究的透明化操作机制使代理成为可观察、可理解、可干预的助手，在一次次成功协助中逐步积累用户的信任。
