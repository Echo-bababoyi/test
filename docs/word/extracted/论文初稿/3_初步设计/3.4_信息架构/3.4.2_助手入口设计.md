# 3.4.2 助手入口设计

小浙助手不占用独立页面，也不占用底部导航栏位置。底部导航保持“首页”和“我的”两项，与原浙里办长辈版完全一致，避免增加老年用户的认知负担。

助手以悬浮按钮的形式叠加在业务页面之上。具体设计如下：悬浮按钮吸附于屏幕右侧边缘，为圆形橙色按钮，中央为白色“浙”字。按钮支持拖动，松手后自动吸附至左或右边缘，且不遮挡页面的核心内容区域。点击按钮后，从右下角弹出气泡聊天窗。当存在未读消息时，按钮会显示红点提示并伴有脉冲动画以吸引注意。聊天窗关闭后，按钮重新出现，用户可随时再次唤起。

该设计的核心考量是：代理扮演随叫随到的辅助角色，而非强制介入的主导界面。老年用户在不需要帮助时，悬浮按钮安静地停留在屏幕边缘，不干扰正常操作流程；需要帮助时，仅需一次点击即可唤起代理，无需记忆任何复杂的导航路径。
