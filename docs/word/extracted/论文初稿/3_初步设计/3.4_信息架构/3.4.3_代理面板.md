# 3.4.3 代理面板

气泡聊天窗以浮层形式叠加在业务页面之上，不触发路由跳转，业务页面始终保持可见。聊天窗采用适度大小的浮层，默认位于屏幕右下角（支持拖动），上方的业务页面完整可见，老年用户始终能够清晰地知道自己当前位于哪个操作页面。

当代理需要引导用户关注某个界面元素时，该元素会自动高亮显示，如橙色脉冲描边效果，帮助老年用户快速定位到目标操作区域。

聊天窗内部结构清晰，包含可滚动的对话气泡区、文字输入框、语音输入按钮及发送按钮。语音输入功能集成语音识别能力，用户可长按说话，系统自动将语音转为文字。

与常见的底部半屏面板方案相比，浮动气泡窗的主要优势在于：业务页面完全可见，老年用户可以一边观察页面内容，一边与代理进行对话，不会产生页面被遮住的空间迷失感。
