# 3.5 低保真原型

低保真原型阶段采用灰度线框图，重点验证信息层级与交互流程，不涉及视觉细节。本研究共绘制4张关键界面线框图，覆盖长辈版核心交互路径。

关键界面草图：

（1）长辈版首页：底部导航两项（首页 / 我的），小浙助手悬浮按钮吸附右侧边缘；首页格栅展示高频服务（医保、养老金、社保等），字号大、图标大，操作区域集中在屏幕下方，便于单手使用；

（2）医保缴费页（代理辅助填表）：已填字段显示灰色填充值，敏感字段（缴费金额）标注"需您确认"；代理在气泡窗中提示“缴费金额请您亲自确认”，体现止步于支付的受控边界；

（3）代理气泡聊天窗：浮动于页面右下角，含对话气泡区 + 文字输入框，业务页面完整可见；

（4）授权卡片：在气泡窗内弹出，居中显示"小浙想帮您填【身份证号】，这次可以吗？"，两个大按钮（可以 / 不用了），15 秒超时自动拒绝；
