# 3.8 高保真原型

高保真原型覆盖全部4个核心场景的完整交互流程，包含代理面板、授权弹窗、高亮动效、字段填充动画等所有视觉和交互细节，可在浏览器中直接运行和演示。

动效设计以自然、柔和为原则，避免突兀的切换造成老年用户的困惑。具体而言：

代理面板从底部平滑滑入滑出，打开和关闭过程连贯自然；

面板在执行长任务时可收缩为迷你条，减少对页面的遮挡；

授权卡片从面板内向上弹出，明确提示用户需要做出选择；

页面切换采用淡入淡出过渡，避免视觉跳跃；

高亮元素以脉冲描边效果吸引注意，避免采用闪烁等可能引起不适的动效。

以下以四个典型页面为例说明高保真原型的实现效果：

1. 长辈版首页（含代理面板）：底部代理面板滑出，占屏幕约 55%；上方首页格栅服务区覆盖半透明蒙层仍清晰可见；面板内显示问候气泡与麦克风按钮。

2. 刷脸认证页：橙色主题取景框居中，右下角小浙气泡紧凑叠加，提示认证步骤，不遮挡取景框。

3. 养老金查询结果页：查询结果以大字卡片展示，代理面板同步显示结果摘要，实现屏幕与语音双通道呈现。

4. 草稿箱页：列表展示未完成表单草稿，点击可跳转回对应页面并恢复已填内容，体现自动保存与断点续填的容错设计。
