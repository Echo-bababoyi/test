# 4.2.1 技术选型与工具链

框架：Flutter Web（Dart），构建跨平台 Web 应用，在 Chrome 浏览器上运行。

路由：GoRouter，配置 17 条路由，代理指令通过 context.go() 触发页面跳转

状态管理：Riverpod。全局状态（登录态、当前模式）通过 NotifierProvider 管理，代理面板内部状态采用 StatefulWidget 管理，两层分离保证面板可独立复用。

本地存储：IndexedDB（通过 idb_shim Dart 包），用于草稿箱和操作记录的持久化。

语音录制：浏览器 MediaRecorder API，长按麦克风按钮录音，松开后将音频 base64 编码经 WebSocket 发送至后端讯飞 ASR 识别。

开发工具链：项目级 Flutter SDK，镜像源 pub.flutter-io.cn，与系统环境隔离。

状态管理架构说明：全局状态（loginProvider 登录态、modeProvider 长辈/标准模式切换）使用 Riverpod NotifierProvider，在 ProviderScope 根节点注入，全应用响应式更新。代理面板（AgentPanel）内部维护独立的 SessionState 对象（会话 ID、对话历史、已授权权限集合、WebSocket 连接状态），面板关闭时随之销毁，不污染全局状态——在架构上保证了“权限随会话消亡”的语义。
