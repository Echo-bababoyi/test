# 4.2.2 代理 UI 层实现

代理 UI 层的核心组件如下表所示。

表4.2 代理 UI 层的核心组件

| 组件 | 文件 | 职责 |
| --- | --- | --- |
| AgentPanel | widgets/agent_panel.dart | 底部面板主体，滑动动画，对话气泡区，WebSocket 消息分发 |
| MicButton | widgets/mic_button.dart | 麦克风大按钮，长按启动 MediaRecorder 录音，松开后将音频 base64 发送至后端 ASR |
| AuthCard | widgets/auth_card.dart | 授权弹窗卡片，含 15 秒超时自动拒绝 |
| AgentCommandExecutor | services/agent_command_executor.dart | 解析后端指令（cmd_navigate/highlight/fill_field/press_button），驱动前端执行 |
| AgentElementRegistry | services/agent_element_registry.dart | GlobalKey 注册表，代理通过语义 key 查找页面元素位置 |
| AgentBubble | widgets/agent_bubble.dart | 小浙对话气泡，含三点跳动等待动画 |
| WsClient | services/ws_client.dart | WebSocket 单例客户端，消息收发 |
| SessionState | services/session_state.dart | 代理会话内部状态（会话 ID、对话历史、已授权权限集） |
| DraftService | services/draft_service.dart | 草稿箱读写，表单字段自动快照到 IndexedDB |

表4.2（续） 代理 UI 层的核心组件

| 项目内容 | 特点 |  |
| --- | --- | --- |
| AudioPlayer | services/audio_player.dart | 播放 base64 mp3（TTS 音频），含 onEnded 回调 + 30 秒超时兜底 |
| PressScaleWrapper | widgets/press_scale_wrapper.dart | 通用按下缩放+变色组件，包裹所有可交互元素 |

组件协作关系：AgentPanel 持有 WsClient 的消息流订阅，收到后端消息后路由给 AgentCommandExecutor 执行具体指令。AgentCommandExecutor 通过 AgentElementRegistry 查找目标元素的屏幕坐标，触发高亮动效；通过 GoRouter 执行页面跳转；通过直接写入 Flutter Widget 树（GlobalKey + 表单控制器）执行字段填充。整个代理 UI 层以 AgentPanel 为核心，不侵入业务页面的实现逻辑。业务页面只需将可被操作的元素用语义 key 注册到 AgentElementRegistry 即可。
