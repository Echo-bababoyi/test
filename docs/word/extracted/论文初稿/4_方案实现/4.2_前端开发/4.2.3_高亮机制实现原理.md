# 4.2.3 高亮机制实现原理

高亮机制通过以下步骤实现：

业务页面中每个可被代理高亮的元素使用语义化 GlobalKey（如 Key('btn_go_payment')）注册到全局 agentElementRegistry；

收到 cmd_highlight 消息后，通过 BuildContext 和 GlobalKey 查找元素的 RenderBox，获取其屏幕坐标和尺寸；

在屏幕全局 Overlay 上绘制高亮描边（橙色脉冲动画），覆盖于蒙层之上；

蒙层（IgnorePointer + ColorFiltered）在高亮元素区域挖空，使其可见且可点击。

代理只知道语义 key（如 btn_go_payment），不知道 DOM 结构——这是前端安全边界，未注册的元素代理无法操作。
