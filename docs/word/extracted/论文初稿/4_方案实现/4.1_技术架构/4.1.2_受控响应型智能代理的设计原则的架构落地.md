# 4.1.2 受控响应型智能代理的设计原则的架构落地

代理永远不主动。在架构层面，WebSocket Handler 仅在收到前端发送的 agent_wake 消息时才会创建 Agno Agent 实例并开始运行。连接建立期间，后端完全静默，不会主动推送任何消息或执行任何操作，从源头保证了代理的非侵入性。

确定性操作止步。所有涉及不可逆后果的确定性按钮如，“登录”“去支付”，均不注册为 Agno 工具，使得代理在物理层面无法调用这些按钮。与此同时，前端也对按钮的点击事件进行拦截校验，双重保障确保代理永远不会代为触发此类操作。

权限一事一授。敏感操作工具（如 fill_field_sensitive、read_sms）在 agent_core.py 中被列入 _SENSITIVE_TOOLS 集合。WebSocket Handler 在每次工具调用前会检查该集合：若命中，则立即暂停 Agno 执行，向前端推送 permission_request 消息，等待用户当场授权后方可恢复执行。授权仅当次任务有效，任务结束后自动失效。
