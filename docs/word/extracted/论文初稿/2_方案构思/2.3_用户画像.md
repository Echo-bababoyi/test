# 2.3 用户画像

基于前期在杭州市西湖区三个典型老年社区及政务大厅等场景，对7位60岁以上老年用户的半结构式访谈与参与式观察，本研究提炼出以下目标用户画像。

数字生活特征：该群体在社交与生活类应用中表现相对熟练，能够独立使用微信进行语音通话、视频通话和收发红包，也会使用美团、支付宝等进行扫码支付。然而，在政务APP操作上存在明显困难，主要障碍集中在多级菜单导航、验证码输入、人脸识别以及页面跳转后的流程中断或迷失。由于多数政务APP界面布局与消费类应用差异较大，老年用户难以将已有数字经验迁移至政务场景。

典型行为模式：当遇到操作困难时，老年用户的第一反应并非放弃，而是求助。求助对象以子女为主，但受子女工作时间和耐心程度限制，求助体验不稳定。线下政务大厅工作人员因专业、耐心，被视为更可靠的求助渠道。部分用户会因一次失败操作而长期回避该功能模块，形成“尝试、受挫、放弃、依赖线下”的行为闭环。

核心心理特征：该群体呈现出“信任人胜过信任系统”的典型心理：只有在有人帮助时才感到安心。对操作出错怀有较强的恐惧心理，担心造成不可逆的经济损失，心理负担往往大于实际的技术障碍。概括而言，老年用户并非不愿使用线上服务，而是对独立操作缺乏信心，他们最需要的不是更清晰的界面，而是可信赖的帮助。
