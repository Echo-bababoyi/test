# 2.1.1 设计创新点

本研究的核心创新是提出并实现受控响应型智能代理这一交互模式。

相较于当前信息服务APP中常见的AI助手，本研究所提出的智能代理在能力上有本质区别。现有AI助手多停留在对话式咨询层面，给出相关的流程指导，但最终仍需用户自己去实际操作相关流程。而本研究的智能代理则具备直接的任务执行能力，可以代为完成页面跳转、表单填写等步骤繁琐但规律性强的操作，从而切实减轻老年用户的认知与操作负担。

相较于通用智能代理追求最大化自主完成任务的技术路线，为了回应老年用户对智能代理的信任缺失与控制权的双重顾虑，本研究将智能代理定位为“受控响应型智能代理”：代理仅在获得用户明确授权后协助操作，而非主动替用户决策和执行。为了实现上述受控性，本研究设计了受控响应型智能代理的设计原则和权限等级，以及透明化操作机制。
