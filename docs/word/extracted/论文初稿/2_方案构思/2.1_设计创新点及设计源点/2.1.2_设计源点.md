# 2.1.2 设计源点

本研究的设计源点来自前期实地调研中的一项核心发现：老年用户在使用信息服务APP时，如果无法独立完成相关流程，会更倾向于前往线下服务大厅寻求工作人员的帮助或向子女求助。这两种协助方式存在两个共同特征：其一，老年用户信任协助者；其二，协助者可以帮助老年用户完成部分简单、低风险的操作。由此，本研究提出的受控响应型智能代理，正是在获取低风险、规律性强的操作权限的同时，尝试与老年用户建立信任关系，并将线下协助的服务模式复刻到线上。

前期实地调研进一步显示，在政务大厅场景中，当老年用户遇到操作困难时，窗口工作人员的协助行为大致可总结为以下步骤：

意图理解：倾听和理解老年用户要办理的具体业务；

任务确认：通过复述确认需求，如“您是要办医保缴费，对吗？”；

按需协助：引导老人跟随步骤操作，必要时提供帮助，或者代为填写部分非敏感信息；

边界止步：在提交、支付等关键节点止步，由老人自己确认和操作；

结果反馈：操作完成后告知结果。

本研究将这一线下服务模式映射至线上，通过受控响应型智能代理实现数字化复刻。代理的交互逻辑严格参照线下工作人员“有耐心、有礼貌、会引导、懂边界”的行为标准进行设计，使线上协助体验尽可能贴近老年用户熟悉的线下服务场景。
