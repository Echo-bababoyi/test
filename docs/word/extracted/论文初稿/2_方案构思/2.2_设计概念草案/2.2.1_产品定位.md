# 2.2.1 产品定位

本研究以浙江省政务服务APP“浙里办”为应用场景，面向老年用户，设计一款集成受控响应型智能代理“小浙”的适老化长辈版。与现有长辈版主要采用大字体、简界面等传统适老化策略不同，本产品通过语音对话为主的多模态交互方式，将线下向窗口工作人员求助的协助体验复现至线上，实现从自助服务到协助服务的模式转变。

代理“小浙”严格遵循前文提出的适老化智能代理的权限等级和设计原则，并配备有透明化操作机制，使用户在享受便捷协助的同时，始终保有对账户安全的最终控制权。

产品愿景：成为老年用户在政务APP中可信赖的线上工作人员——用户只需说出需求，代理就能引导、协助完成操作，同时用户始终保持最终控制权。
