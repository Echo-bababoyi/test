# 1.1.3 研究流程与方法

本研究遵循"问题发现、文献研究、设计实践、原型实现、可用性验证"的整体研究路径，具体研究流程与方法如下：

第一阶段：实地调研与问题发现

深入杭州市西湖区三个典型老年社区及政务大厅，对 7 位 60 岁及以上的老年用户进行半结构式访谈与参与式观察，提炼其使用信息服务APP的核心痛点与心理洞察。

第二阶段：文献研究与理论建构

系统梳理适老化设计、多模态交互、智能代理三个领域的国内外研究，识别现有研究不足，提出受控响应型智能代理的设计框架与设计原则：代理原则上不主动，确定性操作代理止步，以及权限一事一授。

第三阶段：设计方案构思与迭代

基于用户研究洞察，构建用户画像与用户旅程图，设计信息架构与低保真原型，通过快速走查对方案进行迭代修正，最终完成高保真交互与视觉设计方案。

第四阶段：原型开发与实现

以前后端分离架构和智能代理框架搭建高保真可交互原型，完成核心场景的功能实现，接入大语言模型、语音识别与语音合成能力，构建多模态智能代理交互体验。

第五阶段：可用性测试与总结

在实际移动设备上进行原型系统的可用性测试，验证设计方案的有效性，在此基础上总结受控响应型智能代理的设计启示与局限。
