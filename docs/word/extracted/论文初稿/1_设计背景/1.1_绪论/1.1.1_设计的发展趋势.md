# 1.1.1 设计的发展趋势

本研究关注的信息服务APP适老化设计，其发展趋势主要体现在以下三个方面：设计重心从表层感官的适老化向深层交互逻辑延伸，交互方式从单一通道向多模态协同演进，以及系统角色从被动工具向主动代理转变。

在适老化设计方面，早期研究侧重于弥补老年人感官与认知的功能衰退。Farage等的经典综述系统梳理了老年人在视觉、听觉、触觉、移动平衡和记忆注意力等方面的功能变化，并据此提出了提高对比度、控制声音频率范围、提供多通道反馈、简化任务流程等的具体设计指南[1]。这些以补偿为核心的设计原则奠定了适老化改造的基础，但整体上仍聚焦于界面元素的被动调整。张晓宇等构建了包含系统易用性、系统包容性、情感支持度、服务有效度四个维度的适老化设计评价指标体系，其研究进一步指出，当前适老化改造多停留在放大字体、简化界面等表层优化，而交互逻辑、容错机制、情感化设计仍有不足。这表明，适老化设计的重心正逐渐从表层感官的基本可及性，向深层的用户体验延伸[2]。

在交互方式上，多模态协同已成为信息服务APP适老化设计重要发展趋势。Wang等分析了31项关于老年人智能交互界面的研究，将交互形式分为手势交互、语音交互、多模态交互和人工智能交互四类[3]。其中，语音交互因其能够绕开视觉与操作障碍，被视为适老化设计的重要突破口。但单通道交互难以覆盖老年人多样化的使用情境与能力差异，由此推动了多模态协同的探索。多模态协同的关键不在于通道数量的叠加，而在于通道间的语义融合与时序对齐，即同一信息须在多个通道中以相互强化而非相互干扰的方式传递。这一原则的提出，标志着多模态设计正从追求通道数量的增加，转向追求通道间的智能协同。

在技术路径上，智能代理正从被动响应转向主动辅助。Wooldridge等将智能代理的核心属性归纳为自主性、反应性、主动性和社交能力四要素，为智能代理奠定了概念基础[4]。Jaiswal 等在其综述中进一步梳理了当前智能代理在规划、记忆、反思与目标追求等方面的能力机制[5]。这一趋势在适老化领域已初见应用：Lee等提出的任务导向型多模态代理系统（TOMAS），通过简化用户界面和整合语音命令，帮助老年人更独立地使用智能手机上的各类信息服务[6]。从遵循预设规则的被动工具，到能够理解意图、自主规划任务的主动代理，这一转变正在重塑老年用户与信息服务APP之间的关系。
