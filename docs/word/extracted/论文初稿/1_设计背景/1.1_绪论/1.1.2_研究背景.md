# 1.1.2 研究背景

我国已步入中度老龄化社会。截至2025年底，60岁及以上老年人口达3.23亿，占总人口比例23.0%。与此同时，移动互联网的普及使各类信息服务APP正在成为公众日常生活不可或缺的工具。然而，老年群体在使用这些APP时普遍面临“数字鸿沟”的困境。前期调研发现，老年用户并非不愿线上办事，而是不想在线上自己冒险办事——相比独自操作，他们更倾向于去线下服务大厅寻求工作人员帮助。老年用户最渴望的不是更清晰的界面，而是可信赖的帮助。这种信任人胜过信任系统的心理，是阻碍老年用户跨越数字鸿沟的深层障碍，同时也要求信息服务从传统的自助服务模式向协助服务模式转变。

近年来，以大语言模型为基础的智能代理技术快速发展。Gartner将代理式人工智能列为2025年十大技术趋势之首，预测到2028年全球15%的日常工作决策将由具备自主决策能力的AI代理完成[7]。智能代理依靠感知能力、规划能力、记忆能力及工具使用能力，能够理解用户意图、拆解复杂任务、调用工具执行操作，为构建“线上工作人员”的智能代理角色提供了技术可能。同时，多模态交互技术的发展使系统能够整合语音、触控、视觉等多种模态。研究显示78%的老年人倾向于支持多种输入方式的界面，针对认知老化的个性化多模态界面能将老年人可用性提升30%，为老年用户提供更自然、更包容的交互方式[8]。

政策层面，2020年国务院办公厅印发《关于切实解决老年人运用智能技术困难的实施方案》，2021年工信部发布《移动互联网应用（APP）适老化通用设计规范》，2026年国务院办公厅印发《政务移动互联网应用程序规范化管理办法》，鼓励利用人工智能等新技术提升服务体验。广东省已发布《移动政务“适老化”用户体验设计标准》，标志着信息服务APP适老化设计正从实践探索走向标准化。

然而，现有研究仍存在不足：第一，智能代理在信息服务APP适老化场景中的应用研究较少，缺乏针对性的设计框架；第二，多模态交互与智能代理的融合设计研究不足，如何通过多模态交互让代理协助而非替代老年人操作，尚缺乏相关系统探索；第三，老年用户对智能代理的信任机制与授权机制研究薄弱。因此，本研究聚焦于信息服务APP的适老化设计与多模态交互研究，探索受控响应型智能代理的应用路径，具有重要的理论意义与实践价值。
