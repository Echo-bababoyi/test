# 2 国内外现状

## 2.1 国外研究现状

国外在信息服务APP适老化设计与多模态交互领域的研究起步较早，形成了较为系统的理论体系和实证积累。Farage等人的经典综述系统梳理了老年人随年龄增长在视觉功能、听觉功能、触觉感知、移动平衡能力以及记忆注意力方面的正常变化，并针对每一类变化提出了具体设计指南，如提高照明与对比度、控制声音频率范围、提供多通道反馈、简化任务流程等[12] 。

在个性化多模态界面研究方面，Bhattacharya发表的叙述性综述提供了关键数据支撑：相比单一模态系统，78%的老年人更倾向于选择支持多种输入方式（如语音或触控）的界面；AI驱动的预测模型在自适应系统中预测用户偏好的准确率可达95%；针对认知老化的个性化多模态界面能将老年人可用性提升30%，并能促进独立生活，尤其适用于轻度认知障碍人群。该研究还指出，自适应多模态界面通过整合用户和环境情境信息，能够显著提升用户体验和参与度[6]。

在智能代理方面，Lee等提出的任务导向型多模态代理系统（TOMAS）通过简化用户界面和整合语音命令，帮助老年人更独立地使用智能手机上的各类信息服务[13]。 Cuadra等开发的多模态大语言模型代理系统用于健康数据录入，研究显示所有参与者（包括盲人）都能独立完成标准问卷，揭示了多模态交互如何以互补方式提供替代路径[14]。

## 2.2 国内研究现状

国内在信息服务APP适老化设计领域的研究近年来发展迅速，形成了从影响因素分析到评价体系构建再到设计实践的系统化研究路径。 张晓宇等构建了包含系统易用性、系统包容性、情感支持度、服务有效度四个维度的适老化设计评价指标体系，并对典型政务APP进行了实证测评，指出当前适老化改造多停留在放大字体、简化界面等表层优化，而交互逻辑、容错机制、情感化设计仍有不足[3]。

在智能代理与适老化融合方面，张诗棋等通过用户访谈深入了解了老年人对代理型适老软件的需求和体验，为软件设计提供了重要的用户需求参考[15]。在多智能体协同领域，海尔研究团队基于LangGraph框架开发了健康适老家电智能联动系统，利用智能家电作为行为感知节点，集成健康监测、设备控制、行为理解等模块，通过“家电即传感器”理念提升老年用户体验。

在多模态交互研究方面，王斯薇子等以交互情境、模态信息、用户意图三要素为导向，提出包含多源特征采集的感知层、多模态信息融合的处理层和自适应终端反馈的执行层的闭环设计模型，通过建立多模态信息间的动态映射关系实现场景与用户状态的智能适配[16]。
