# 1 设计主题

## 1.1 相关研究

### 1.1.1 信息服务APP适老化设计

信息服务APP是指通过移动互联网向用户提供信息查询、事务办理、资源获取等服务的应用程序，涵盖政务、医疗、金融、生活服务、社交通讯、影音娱乐等多个领域。主流信息服务APP可分为社交通讯、餐饮购物、导航出行、运动健康、实用工具、教育新闻、影音娱乐、休闲游戏、金融理财、便捷生活等10个大类。这些APP已深度融入人们的日常生活，成为获取信息、办理事务、沟通娱乐的重要渠道。

随着移动互联网的普及，各地政府和服务机构纷纷推出移动应用，如浙江“浙里办”、广东“粤省事”等政务平台，以及各类医疗健康、生活缴费类应用。然而，这类APP在提升服务效率的同时，也对用户的数字素养提出了更高要求。对于老年群体而言，这一要求尤为突出。不少老年人不会上网、不会使用智能手机，在出行、就医、消费等日常生活中遇到不便，无法充分享受智能化服务带来的便利，老年人面临的“数字鸿沟”问题日益凸显。

为深入理解老年用户在使用信息服务APP时面临的具体障碍及其成因，现有研究从用户行为层面开展了大量研究。易臣何与朱雯菁等发现，在老年用户使用信息服务app的过程中，感知易用性是影响老年用户持续使用意愿的最根本因素，用户满意度是最直接的因素，而感知有用性、感知信任和感知风险起到承上启下的过渡作用[1]。李梦云等则基于技术接受模型验证了感知易用性、感知有用性、感知信任和代际支持对老年人使用意愿的关键作用，并指出代际技术支持在感知易用性到使用意愿这一转化过程中呈现出调节效应[2]。

### 1.1.2 适老化设计

适老化设计是一种以老年用户为中心的包容性设计范式，要求从老年群体的生理特征、认知能力、心理预期和行为模式出发，对产品、服务或环境进行针对性优化。尽管该概念最初源于物理空间的改造，但其核心理念——降低通行障碍、操作障碍及信息感知障碍——同样适用于数字产品的交互设计。适老化设计的核心目标可以概括为“可用、易用、愿用”三个层次：让老年用户能够顺利完成操作、轻松上手操作、愿意主动使用。其本质并非简单的视觉放大，而是系统性地重构交互逻辑、简化操作流程、建立信任机制。

为衡量适老化设计水平，张晓宇等构建了包含系统易用性、系统包容性、情感支持度、服务有效度四个维度的评价指标体系，并对典型政务APP进行了实证测评。该体系回应了三个目标：系统易用性与包容性指向可用与易用，情感支持度与服务有效度则关乎愿用。研究指出，当前适老化改造多停留在放大字体、简化界面等表层优化，而交互逻辑、容错机制、情感化设计仍有不足[3]。

### 1.1.3 多模态适老化设计

多模态适老化设计是指通过整合语音、触控、手势、视觉等多种交互通道，回应老年人生理与认知功能退化的设计方法。其核心价值在于冗余互补——通过多通道同时传递信息，确保任一感官通道退化不影响信息接收，同时让用户能根据自身能力和场景选择最自然的交互方式。

这一设计思路在学术研究中得到了系统梳理。国际人机交互领域的最新综述分析了31项关于老年人智能交互界面的研究，将交互形式分为手势交互、语音交互、多模态交互和人工智能交互四类。研究发现，手势的简洁性与方向性、语音交互中用户表达的流畅性与系统识别率、界面输入与反馈的模态组合，均会影响老年用户的操作绩效和主观偏好[4]。

在各类多模态交互方式中，语音交互因其能够绕开视觉与操作障碍，被认为是适老化设计的重要突破口，在不少APP中已广泛部署。然而在实际体验中，语音助手功能的问题依然突出。侯文军指出，语音助手是帮助老年人绕开视觉与操作障碍的入口，但目前许多产品只是形式上接入语音模块，却未形成真正可用的交互闭环[5]。语音功能在主流APP中表现出两类典型问题：一类是完全缺失语音交互入口，有的APP在正常模式下具备语音输入方式，但在长辈模式下反而取消了相应功能；另一类是语音功能虽有但存在识别准确率不理想、缺乏反馈确认、与后续界面交互逻辑断层等问题。

Bhattacharya等在其叙述性综述中明确指出，当前研究亟需开展纵向研究和开发无偏算法，以推动自适应系统的进步[6]。现有技术仍面临多模态数据融合和数据集缺乏等难以克服的挑战，未来研究应更加聚焦于开发多模态融合框架和扩大多模态数据库。

### 1.1.4 智能代理

智能代理是指能够感知环境、理解意图、自主规划并调用工具执行任务的软件实体。Wooldridge与Jennings将其核心属性归纳为自主性、反应性、主动性及社交能力。近年来，随着大语言模型的突破，智能代理正从简单的规则响应向具备复杂推理能力演化，其技术架构与能力边界不断拓展[7]。

在技术发展层面，现代AI代理以大语言模型为基础，运用海量知识进行反思与规划，再调用各类工具达成任务，其关键突破在于具备自主性、适应性与目标导向三大核心特性。Jaiswal等在其系统综述中进一步系统梳理了当前AI代理在规划、记忆、反思与目标追求等方面的能力机制[8]。Gartner将代理式人工智能列为2025年十大技术趋势之首，预测到2028年全球15%的日常工作决策将由具备自主决策能力的AI代理完成[9]。

在适老化应用方面，智能代理技术正被探索应用于智慧居家照护领域，通过AI驱动的预测模型和自适应系统，为老年人提供个性化健康管理、日常生活支援与居家安全保障。这类应用的核心在于，智能代理能够理解用户意图并代为完成复杂操作，扮演类似线上助手的角色。然而，传统智能代理所强调的自主性，与老年用户对操作可控性的强烈需求之间存在张力。如何在保留代理核心能力的同时，让用户始终掌握最终控制权，是当前研究尚未解决的难题。

## 1.2 设计案例

### 1.2.1 粤税通——政务APP适老化改造

“粤税通”是广东省税务局推出的移动政务服务平台，其适老化改造基于1.2万条老年用户操作轨迹数据，将城乡居民社保缴费这一高频业务从十余个步骤精简为2个核心步骤，整合了数据自动预填及潮汕方言语音导航等功能。改造后，用户平均操作时间从约7分钟缩短至30秒。“粤税通”的适老化改造展现了基于真实用户数据的系统性适老化设计方法，通过流程简化与方言支持策略进一步优化了老年用户的体验。

### 1.2.2 Mediguide——面向老年患者的虚拟助手

清华大学团队开发的Mediguide是一款通过多模态交互提供个性化导航支持的虚拟助手，旨在帮助老年人在医院环境中完成寻路、支付、理解医疗结果等复杂任务。该助手采用年轻友好的女性形象、白大褂增强可信度，通过AR视觉引导与语音提示相结合的方式，为老年人提供分步骤的操作指引。VR仿真实验表明，Mediguide能够降低认知负荷、减少决策错误，并显著提升老年人的自主性[10]。

### 1.2.3 CareBuddy——多智能体协同老年照护系统

美国约翰霍普金斯大学研发的CareBuddy是一款模块化多智能体对话AI系统，专为阿尔茨海默病患者及其照护者提供个性化协助。系统采用分层架构，由中央协调器统筹多个专业化智能体，分别负责医疗咨询、预约安排、膳食计划、用药提醒等功能。可用性研究表明，85%的用户对系统的预约安排功能评分为满分，90%的用户对系统的膳食规划功能给予高分评价[11]。
