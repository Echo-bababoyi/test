# 1 设计背景

## 1.1 选题背景

我国已步入中度老龄化社会。截至2025年底，60岁及以上老年人口达3.23亿，占总人口比例23.0%。与此同时，移动互联网的普及使各类信息服务APP（政务、医疗、健康、生活服务等）成为公众日常生活不可或缺的工具。然而，老年群体在使用这些APP时普遍面临“数字鸿沟”的困境。调研发现，老年用户并非不愿线上办事，而是不想在线上自己冒险办事——相比独自操作，他们更倾向于去线下服务大厅寻求工作人员帮助。老年用户最渴望的不是更清晰的界面，而是可信赖的帮助。这种信任人胜过信任系统的心理，是阻碍老年用户跨越数字鸿沟的深层障碍，要求信息服务从传统的自助服务模式向协助服务模式转变。

近年来，以大语言模型为基础的智能代理技术快速发展。Gartner将代理式人工智能列为2025年十大技术趋势之首，预测到2028年全球15%的日常工作决策将由具备自主决策能力的AI代理完成[1]。智能代理依靠感知能力、规划能力、记忆能力及工具使用能力，能够理解用户意图、拆解复杂任务、调用工具执行操作，为构建“线上工作人员”提供了技术可能。同时，多模态交互技术的发展使系统能够整合语音、触控、视觉等多种模态。研究显示78%的老年人倾向于支持多种输入方式的界面，针对认知老化的个性化多模态界面能将老年人可用性提升30%，为老年用户提供更自然、更包容的交互方式[2]。

政策层面，2020年国务院办公厅印发《关于切实解决老年人运用智能技术困难的实施方案》，2021年工信部发布《移动互联网应用（APP）适老化通用设计规范》，2026年国务院办公厅印发《政务移动互联网应用程序规范化管理办法》，鼓励利用人工智能等新技术提升服务体验。广东省已发布《移动政务“适老化”用户体验设计标准》，标志着信息服务APP适老化设计正从实践探索走向标准化。

然而，现有研究仍存在不足：一是智能代理在信息服务APP适老化场景中的应用研究较少，缺乏针对性的设计框架；二是多模态交互与智能代理的融合设计研究不足，如何让代理协助而非替代老年人操作尚缺乏系统探索；三是老年用户对智能代理的信任机制与授权机制研究薄弱。因此，本研究聚焦于信息服务APP的适老化设计与多模态交互研究，探索受控响应型智能代理的应用路径，具有重要的理论意义与实践价值。

## 1.2 设计目标与意义

### 1.2.1设计目标

本研究以政务APP为应用场景，针对老年用户信任人胜过信任系统的心理特征，探索基于多模态交互与智能代理的适老化设计路径。具体目标包括：

一是设计多模态交互方案：明确智能代理在适老化信息服务场景中的角色定位，提出受控响应型智能代理的设计理念——代理仅在获得用户明确授权后协助操作，而非追求传统意义上的完全自主性。方案将涵盖代理角色定义、权限分级模型、多模态交互流程设计、信任建立策略等要素。

二是识别核心代理协助场景：基于前期调研痛点和文献研究，确定验证码接收、人脸识别、入口查找、术语解释等最需要代理协助的3-5个核心场景，并针对每个场景设计具体的多模态交互流程，整合语音、触控、视觉等多种模态。

三是产出高保真交互原型：以典型信息服务APP为蓝本，制作可交互的智能代理原型，覆盖核心协助场景。

四是验证设计有效性：邀请5-8位老年用户进行可用性测试，收集任务完成时间、错误率、用户满意度、信任感评分等数据，并根据测试结果迭代优化设计方案。

### 1.2.2设计意义

理论意义方面，本研究是对现有适老化设计研究的重要补充。已有研究从影响因素识别、评价体系构建、多模态交互融合以及智能代理应用等维度进行了有益探索，但对智能代理的自主性与老年用户的控制需求之间的矛盾缺乏系统回应。本研究提出受控响应型智能代理这一交互模式，在保留智能代理核心能力的同时，通过授权机制让用户始终保持最终控制权，探索从自助到协助的范式转变。这一设计定位回应了老年人担忧智能代理权限失控的深层心理需求，为人机交互领域的适老化研究提供了新的理论视角。

实践意义方面，本研究直接回应了老年用户信任人胜过信任系统的核心心理，通过智能代理技术将线下的“工作人员帮助”模式复现到线上，有望从根本上解决老年用户的数字焦虑问题。设计成果可为各类信息服务APP的适老化迭代提供可操作的设计指南，并为后续信息服务APP适老化标准的完善提供实证依据。
