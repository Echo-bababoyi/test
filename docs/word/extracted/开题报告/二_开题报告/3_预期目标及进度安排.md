# 3 预期目标及进度安排

## 3.1预期成果

本研究预期产出以下成果：

（1）毕业设计论文：完整记录研究背景、相关文献综述、用户调研过程、技术调研分析、设计方案阐述、设计验证与迭代全过程。

（2）多模态交互方案：产出一套适用于信息服务APP适老化场景的多模态交互设计规范，涵盖语音、触控、视觉等多模态的协同策略，包括交互流程设计、反馈机制、错误处理与容错策略等，为后续同类设计提供参考。

（3）高保真交互原型：以“浙里办”APP为蓝本，选取老年人高频使用的3-5个核心服务场景（如医保缴费、养老金查询、异地就医备案等），设计并制作集成智能代理与多模态交互功能的仿真APP原型。原型将实现用户语音对话、代理自动操作、语音输入辅助、验证码自动填写等功能。

（4）可用性测试报告：邀请5-8位60岁以上老年用户参与原型可用性测试，收集任务完成时间、操作错误率、用户满意度、信任感评分等定量数据，以及用户主观反馈、改进建议等定性信息，并据此提出迭代优化建议。

## 3.2研究计划

本研究遵循“调研-分析-设计-开发-验证-迭代”的设计流程，具体研究计划如下：

（1）调研阶段：完成用户初步调研，识别老年用户核心痛点；完成相关文献综述，明确研究框架。

（2）补充调研阶段：针对智能代理的角色设定、交互偏好、信任触发点等问题，补充8-10位老年用户的深度访谈，明确代理形象、声音、交互方式的设计方向。

（3）设计阶段：基于调研结果，完成受控响应型智能代理的交互逻辑设计、多模态反馈机制设计、核心场景流程设计，并绘制低保真原型和交互流程图。

（4）技术开发阶段：搭建智能代理服务，开发可运行的仿真APP原型，实现预设的核心功能。

（5）验证阶段：开展可用性测试，收集用户数据并分析设计效果，形成测试报告。

（6）迭代阶段：根据测试结果对原型进行优化完善，形成最终设计方案。

（7）撰写阶段：完成毕业设计报告/论文的撰写与修改，准备答辩。
